# AniRate — Full-Stack Rating & Review Web Application

**AniRate** je full-stack web aplikacija za **ocenjivanje i pisanje recenzija**, inspirisana platformama poput *MyAnimeList*.  
Omogućava korisnicima da pregledaju stavke, ostavljaju ocene i pišu recenzije kroz moderan i responzivan korisnički interfejs.

Projekat je razvijen sa fokusom na **čistu arhitekturu**, **skalabilnost** i **efikasno rukovanje podacima**.

---

## Tehnološki stack

- **Frontend:** Angular, TypeScript  
- **Backend:** NestJS, TypeScript  
- **Baza podataka:** PostgreSQL  

---

## Funkcionalnosti

- Kreiranje, prikaz i upravljanje ocenama i recenzijama  
- Dinamičke Angular komponente za unos i prikaz podataka  
- REST API za CRUD operacije (NestJS)  
- Optimizovana PostgreSQL šema i upiti  
- Jasna podela frontend i backend sloja  
- Kod organizovan za lako održavanje i buduće proširenje  

---

## Opis arhitekture

Aplikacija koristi **REST arhitekturu**, gde frontend komunicira sa backend API-jem radi upravljanja podacima.  
Backend je zadužen za poslovnu logiku i pristup bazi podataka, dok frontend pruža intuitivan i dinamičan korisnički interfejs.

Projekat je pripremljen za buduće funkcionalnosti poput:
- autentikacije korisnika  
- korisničkih profila  
- rang lista i naprednog filtriranja
